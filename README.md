# Классификатор степени обжарки кофейных зерен

## Описание проекта

Приложение использует сверточную нейронную сеть (CNN) для классификации кофейных зерен по степени обжарки на основе изображений. Система обучена на датасете с Kaggle и может идентифицировать четыре различные степени обжарки: зеленые зерна, светлая обжарка, средняя обжарка и темная обжарка.

Проект состоит из веб-приложения Streamlit с бэкендом на базе PostgreSQL для хранения статистики анализа и отзывов пользователей. Приложение позволяет пользователям загружать изображения кофейных зерен и получать результаты классификации с оценками уверенности.

## Основные функции

- **Классификация на основе изображений**: Загрузка изображений кофейных зерен для автоматического определения степени обжарки
- **Оценка уверенности**: Оценка вероятности принадлежности к классу
- **Система обратной связи**: Позволяет пользователям оценивать результаты классификации
- **Отслеживание статистики**: Хранит все результаты анализа в базе данных PostgreSQL
- **Многостраничный интерфейс**: Включает основную страницу анализа, панель статистики и информационные страницы

## Техническая архитектура

### Модель нейронной сети
- **Архитектура**: Пользовательская CNN с 3 сверточными слоями и 3 полностью связанными слоями
- **Вход**: Изображения RGB 224x224
- **Выход**: 4 класса (зеленые, светлая обжарка, средняя обжарка, темная обжарка)
- **Фреймворк**: PyTorch
- **Файл модели**: `models/coffee_model_upgraded.pth`

### Веб-приложение
- **Фреймворк**: Streamlit
- **Страницы**:
  - Основная страница анализа (`main.py`)
  - Панель статистики (`stats.py`)
  - Информация о приложении (`info.py`)
  - Контакты разработчика (`developer.py`)

### База данных
- **Система**: PostgreSQL
- **Таблицы**: Таблица статистики для хранения результатов анализа, временных меток и отзывов пользователей
- **Подключение**: Управляется через `common.py` с помощью менеджеров контекста для безопасных операций с базой данных

## Установка и настройка

### Локальная установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/VBadazhkov/BeansAI.git
cd BeansAI
```

2. Установите зависимости Python:
```bash
pip install -r requirements.txt
```

3. Настройте учетные данные базы данных в `.streamlit/secrets.toml` (в корневой папке):
```toml
USER="postgres"
PASSWORD="0342"
HOST="localhost"
PORT="5432"
DATABASE="coffee"
```

### Развертывание с помощью Docker

1. Соберите и запустите контейнеры:
```bash
docker-compose up --build
```

2. Приложение будет доступно по адресу `http://localhost:8501`

## Инструкции по использованию

1. **Откройте веб-интерфейс** по развернутому URL
2. **Загрузите изображение кофейных зерен** с помощью загрузчика файлов (поддерживаются форматы JPG/PNG)
3. **Нажмите "Анализировать"** для обработки изображения
4. **Просмотрите результаты**, показывающие классификацию обжарки и процент уверенности
5. **Предоставьте обратную связь** с помощью системы рейтинга звездами
6. **Просмотрите статистику** в разделе Статистика, чтобы увидеть исторические данные анализа

## Обучение модели и разработка

Нейронная сеть была обучена на [Coffee Bean Dataset](https://www.kaggle.com/datasets/sot2542/coffee-bean-dataset-v1/data) с Kaggle. Набор данных содержит изображения кофейных зерен с разными степенями обжарки.
